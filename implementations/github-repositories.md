# GitHub Implementations

The following repositories provide concrete implementations or
infrastructure relevant to tool-using and agentic AI systems. They are
selected because their code can help researchers build, inspect, govern,
or evaluate tool-enabled agents.

## 1. OpenAI Agents SDK

**Repository:** openai/openai-agents-python

**Purpose:** Python implementation of the OpenAI Agents SDK.

**Why it is relevant:** Provides agents, function tools, handoffs,
guardrails, sessions, tracing, and MCP integration, making it suitable
for experiments involving tool selection and execution.

**GitHub:** https://github.com/openai/openai-agents-python

------------------------------------------------------------------------

## 2. LangChain

**Repository:** langchain-ai/langchain

**Purpose:** Open-source framework for building LLM applications and
agents.

**Why it is relevant:** Provides tool abstractions and agent execution
components that can be used to construct multi-tool experimental
environments.

**GitHub:** https://github.com/langchain-ai/langchain

------------------------------------------------------------------------

## 3. Microsoft AutoGen

**Repository:** microsoft/autogen

**Purpose:** Framework and implementation for agentic and multi-agent
applications.

**Why it is relevant:** Supports agent coordination and tool-enabled
workflows and is useful for studying action selection in multi-agent
settings.

**GitHub:** https://github.com/microsoft/autogen

------------------------------------------------------------------------

## 4. LlamaIndex

**Repository:** run-llama/llama_index

**Purpose:** Framework for LLM applications involving data, retrieval,
agents, and tools.

**Why it is relevant:** Provides practical components for constructing
tool-enabled agents and retrieval-driven workflows.

**GitHub:** https://github.com/run-llama/llama_index

------------------------------------------------------------------------

## 5. CrewAI

**Repository:** crewAIInc/crewAI

**Purpose:** Framework for orchestrating collaborative AI agents.

**Why it is relevant:** Agents can be equipped with multiple tools,
enabling experiments involving tool availability, delegation, and
tool-use workflows.

**GitHub:** https://github.com/crewAIInc/crewAI

------------------------------------------------------------------------

## 6. AgentOps

**Repository:** AgentOps-AI/agentops

**Purpose:** Agent monitoring, observability, cost tracking, and
benchmarking infrastructure.

**Why it is relevant:** Detailed traces are valuable for measuring
tool-selection accuracy, tool-call frequency, failures, latency, and
cost.

**GitHub:** https://github.com/AgentOps-AI/agentops
