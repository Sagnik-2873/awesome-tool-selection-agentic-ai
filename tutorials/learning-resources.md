# Tutorials and Learning Resources

These resources provide practical and conceptual material for learning
about tool calling, agent construction, evaluation, and agentic
workflows.

## 1. OpenAI API Developer Documentation

**Source:** OpenAI

**What you learn:** API usage, Responses API, built-in tools, function
calling, MCP, and agent development.

**Why it is useful:** Provides primary documentation for implementing
tool-enabled language-model applications and understanding the mechanics
of tool invocation.

**Link:** https://platform.openai.com/docs/

------------------------------------------------------------------------

## 2. OpenAI Agents SDK Documentation

**Source:** OpenAI

**What you learn:** Agents, function tools, handoffs, guardrails,
sessions, tracing, and agent execution loops.

**Why it is useful:** Particularly useful for building controlled
experiments in which multiple tools are available to an agent.

**Link:** https://openai.github.io/openai-agents-python/

------------------------------------------------------------------------

## 3. LangChain Documentation

**Source:** LangChain

**What you learn:** Agents, tools, model integrations, structured
outputs, retrieval, and application orchestration.

**Why it is useful:** Provides practical examples for constructing
tool-enabled agents and testing alternative tool configurations.

**Link:** https://python.langchain.com/

------------------------------------------------------------------------

## 4. Microsoft AutoGen Documentation

**Source:** Microsoft

**What you learn:** Agent construction, multi-agent workflows, tool use,
conversations, and orchestration.

**Why it is useful:** Useful for studying tool-enabled agents and
multi-agent systems in which decisions may be distributed among multiple
components.

**Link:** https://microsoft.github.io/autogen/

------------------------------------------------------------------------

## 5. LlamaIndex Documentation

**Source:** LlamaIndex

**What you learn:** Agents, tools, retrieval, data connectors,
workflows, and LLM application development.

**Why it is useful:** Useful for implementing agents that combine
retrieval and external tools.

**Link:** https://docs.llamaindex.ai/

------------------------------------------------------------------------

## 6. CrewAI Documentation

**Source:** CrewAI

**What you learn:** Agents, tasks, crews, tools, memory, and multi-agent
workflows.

**Why it is useful:** Provides practical examples for assigning multiple
capabilities to agents and studying collaborative tool use.

**Link:** https://docs.crewai.com/

------------------------------------------------------------------------

## 7. ReAct Paper and Research Material

**Source:** Yao et al.

**What you learn:** The reasoning-and-acting paradigm for language-model
agents.

**Why it is useful:** ReAct provides foundational conceptual material
for understanding how reasoning and external actions can be interleaved.

**Link:** https://arxiv.org/abs/2210.03629

------------------------------------------------------------------------

## 8. Toolformer Paper and Research Material

**Source:** Schick et al.

**What you learn:** How language models can learn to invoke external
tools and APIs.

**Why it is useful:** Directly connected to the problem of deciding when
and how a model should use external tools.

**Link:** https://arxiv.org/abs/2302.04761
