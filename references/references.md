# Verified Scholarly References

## Topic

**Evaluating Tool-Selection Accuracy in Multi-Tool Agentic AI Systems**

This collection contains **20 unique scholarly publications** relevant
to tool-using language models, API selection, tool calling, agent
evaluation, and multi-tool agentic systems. Each entry includes
bibliographic information and a persistent identifier or official
scholarly source.

------------------------------------------------------------------------

## 1. ReAct: Synergizing Reasoning and Acting in Language Models

**Authors:** Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran,
Karthik Narasimhan, Yuan Cao\
**Year:** 2023\
**Venue:** International Conference on Learning Representations (ICLR
2023)\
**Identifier:** arXiv:2210.03629\
**Official source:** https://arxiv.org/abs/2210.03629

**Relevance:** ReAct interleaves reasoning and external actions,
providing a foundational framework for agents that interact with
external environments and tools.

------------------------------------------------------------------------

## 2. Toolformer: Language Models Can Teach Themselves to Use Tools

**Authors:** Timo Schick, Jane Dwivedi-Yu, Roberto Dessi, Roberta
Raileanu, Maria Lomeli, Eric Hambro, Luke Zettlemoyer, Nicola Cancedda,
Thomas Scialom\
**Year:** 2023\
**Venue:** Advances in Neural Information Processing Systems (NeurIPS
2023), Volume 36\
**DOI:** 10.52202/075280-2997\
**Official source:**
https://proceedings.neurips.cc/paper/2023/hash/d842425e4bf79ba039352da0f658a906-Abstract-Conference.html

**Relevance:** Toolformer explicitly studies how language models learn
to decide which APIs to call, when to call them, what arguments to pass,
and how to incorporate returned results.

------------------------------------------------------------------------

## 4. ToolBench: Towards Mastering Every Tool for LLMs
